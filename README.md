A one-line entry for the make.fun competition "Funniest Cat Voicemail
Greeting": a voicemail greeting recorded by a cat.

## The entry (106 characters)

> You have reached the cat. I am asleep on your keyboard. Leave a message after the purr. I will not listen.

106 characters, one line, inside the gate of 1–120 characters. The
greeting is the cat speaking, not its owner: it is asleep on the
keyboard (a very cat place to nap), it swaps the voicemail beep for a
purr, and it refuses to listen — the punch lands on the last four
words, in the cat's own flat voice.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the line above, with no trailing newline.
